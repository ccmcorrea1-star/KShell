# Application Launching Context

This context defines the terms used when a person finds and chooses a desktop application through Klauncher.

## Language

**Desktop Entry**:
A named description of a launchable application, including the information a person needs to recognize and open it.
_Avoid_: Application entry

**Application**:
A launchable desktop program presented as a choice in the launcher.
_Avoid_: App

**Application Selection**:
The application a person chooses from the applications currently shown by the launcher.
_Avoid_: Selected result

**Launcher Query**:
Text entered by a person to narrow applications by their name or descriptive label.
_Avoid_: Filter text
